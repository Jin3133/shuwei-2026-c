## 1. 总体关系

```text

```

还需生成三类模型数据：

```text
q1_windows.parquet

```

对应关系：

```text

```

## 2. Q1：手部运动状态预测

### 2.1 每个样本表示什么

每个样本表示：

> 某条记录中某只手在连续历史窗口内的运动，及其未来若干时刻的真实位移。

左右手作为不同样本处理，但保留`hand`字段。

### 2.2 模型输入

建议第一版状态：

\[
x_t=[\Delta p_t,v_t,q_t,h]
\]

其中：

| 变量 | 含义 | 维度 |
|---|---|---:|
| `relative_position` | `p_t-p_window_start` | 3 |
| `velocity` | 因果后向差分速度 | 3 |
| `quality` | 当前观测质量或可靠性 | 1 |
| `hand` | left/right标记 | 1 |

默认不输入：

```text
dataset ID
episode_uuid
sample
世界坐标绝对原点
语义描述description
未来质量信息
```

`episode_uuid、dataset、sample`只作为追踪和分层评估字段。

### 2.3 模型目标

推荐预测相对当前时刻的未来位移：

\[
y_h=p_{t+h}-p_t
\]

首轮预测时距：

```text
0.2s
0.5s
1.0s
```

模型输出形状：

```text
[H, 3]
```

其中`H`是预测时距数量，3代表x/y/z。

若主模型输出概率分布，则增加：

```text
pred_mean: [H, 3]
pred_std 或 pred_covariance: [H, 3] 或 [H, 3, 3]
```

第一版可以先只输出点预测，之后再加入不确定性头。

### 2.4 `q1_windows.parquet`建议字段

| 字段 | 含义 |
|---|---|
| `window_id` | 窗口唯一ID |
| `episode_uuid` | 来源记录 |
| `dataset` | 仅用于分层评估 |
| `split` | 官方划分 |
| `hand` | left/right |
| `continuity_block_id` | 连续时间块 |
| `anchor_timestamp_s` | 输入窗口最后时刻 |
| `input_timestamps_s` | 历史时间数组 |
| `input_relative_position` | `[L,3]` |
| `input_velocity` | `[L,3]` |
| `input_quality` | `[L,1]` |
| `target_horizons_s` | `[0.2,0.5,1.0]` |
| `target_displacement` | `[H,3]` |
| `target_ref_ok` | 每个目标是否可作真值 |

### 2.5 窗口生成条件

- 不跨`episode_uuid`；
- 不跨`continuity_block_id`；
- 输入历史满足`fit_ok=true`；
- 监督目标满足`ref_ok=true`；
- 不跨明显时间断点；
- 不跨train/validation/test；
- 速度只使用当前和过去位置；
- 输入质量不能使用锚点之后的信息。

## 3. Q2：遮挡期间预测与重新观测

### 3.1 每个样本表示什么

每个样本表示：

> 在真实连续可靠轨迹上，从某时刻开始隐藏观测，检查模型在遮挡期间的预测误差和不确定性。

### 3.2 模型输入

```text
遮挡开始前的历史运动窗口
最后可见状态
已遮挡时长
历史观测质量
重新观测动作历史
```

严格禁止输入：

```text
mask区间内真实位置
重新观测返回延迟结束前的结果
未来质量标记
未来语义区间信息
```

### 3.3 模型输出

运动预测模型输出：

```text
pred_position 或 pred_displacement
prediction_uncertainty
```

重新观测策略输出：

```text
action = 0：继续预测
action = 1：发起重新观测
```

可以采用阈值策略：

\[
a_t=\mathbb{1}(U_t>\tau)
\]

### 3.4 `q2_masks.parquet`建议字段

| 字段 | 含义 |
|---|---|
| `mask_id` | mask样本唯一ID |
| `source_window_id` | 对应Q1窗口 |
| `episode_uuid` | 来源记录 |
| `dataset` | 分层评估 |
| `split` | 官方划分 |
| `hand` | left/right |
| `mask_start_s` | 遮挡开始时刻 |
| `mask_duration_s` | 0.2/0.5/1.0/1.5/2.0秒 |
| `history_position` | 遮挡前历史状态 |
| `history_velocity` | 遮挡前历史速度 |
| `last_visible_position` | 最后可见位置 |
| `target_timestamps_s` | 遮挡期间评估时刻 |
| `target_position` | 仅评估端使用的真实轨迹 |
| `target_ref_ok` | 真值可靠性 |

### 3.5 输出评估指标

```text
ADE：遮挡期间平均位移误差
FDE：遮挡结束位置误差
不同mask时长的误差曲线
不确定性校准误差
重新观测次数
等待时间
预测误差 + 观测成本的综合目标
```

## 4. Q3：作业时长概率预测

### 4.1 每个样本表示什么

每个样本表示：

> 某个eligible操作区间在只观察前0.2、0.6或1.0秒时，对完整任务时长进行概率预测。

只使用：

```text
segments.eligible = true
```

当前可用区间数为343。

### 4.2 模型输入

低成本第一版特征：

| 特征 | 含义 |
|---|---|
| `observed_ratio` | 已观察时间/真实时长，仅训练分析时使用时需防泄漏；在线输入不应使用真实时长计算 |
| `prefix_duration_s` | 0.2/0.6/1.0 |
| `displacement` | 前缀首尾位移 |
| `mean_speed` | 平均速度 |
| `max_speed` | 最大速度 |
| `speed_std` | 速度标准差 |
| `terminal_speed` | 前缀结束时速度 |
| `speed_trend` | 末速度减初速度 |
| `two_hand_distance` | 双手距离统计 |
| `bad_ratio` | 前缀内坏质量比例 |
| `visible_ratio` | 可用观测比例 |
| `family_id` | P/A/L |

注意：`observed_ratio=prefix_duration/真实完整时长`会使用目标信息，不能作为在线模型输入。若保留，只能用于离线分析。在线输入应使用固定已知的`prefix_duration_s`。

默认不输入：

```text
dataset ID
description
完整duration_s
前缀结束后的任何轨迹
test统计量
```

### 4.3 模型目标与输出

标签：

```text
target_duration_s = segments.duration_s
```

模型不只输出均值，建议输出：

```text
duration_q50
duration_q80
duration_q90
```

或者输出一个参数化概率分布：

```text
distribution_parameters
```

第三问调度默认使用风险分位数：

\[
b_j=Q_{0.8}(d_j)
\]

### 4.4 `q3_prefix_features.parquet`建议字段

| 字段 | 含义 |
|---|---|
| `prefix_id` | 样本唯一ID |
| `segment_id` | 官方区间ID |
| `episode_uuid` | 来源记录 |
| `dataset` | 仅分层评估 |
| `split` | 官方划分 |
| `family_id` | P/A/L |
| `prefix_duration_s` | 0.2/0.6/1.0 |
| `n_prefix_frames` | 前缀帧数 |
| `visible_ratio` | 可用帧比例 |
| `bad_ratio` | 坏质量比例 |
| `left/right_displacement` | 左右手位移 |
| `left/right_mean_speed` | 平均速度 |
| `left/right_max_speed` | 最大速度 |
| `left/right_speed_std` | 速度标准差 |
| `left/right_terminal_speed` | 末端速度 |
| `left/right_speed_trend` | 运动趋势 |
| `two_hand_distance_*` | 双手距离统计 |
| `target_duration_s` | 完整区间时长，训练标签 |

## 5. 当前数据还需要做的处理

### 必须完成

#### A. 连续块复核

确认`continuity_block_id`在以下情况会切断：

- `episode_uuid`变化；
- 时间倒退或重复；
- 时间间隔超过阈值；
- 必要时长的连续可靠观测不足。

#### B. 相对位置

每个窗口内部计算：

\[
\Delta p_t=p_t-p_{t_0}
\]

不能对整条记录只减一次起点后直接跨窗口使用。

#### C. 因果速度

采用：

\[
v_t=(p_t-p_{t-1})/(t_t-t_{t-1})
\]

不得使用中心差分，避免读取未来帧。

#### D. 训练集标准化

只在train上拟合：

```text
position mean/std
velocity mean/std
Q3数值特征mean/std
```

保存为：

```text
normalization.json
```

validation和test只能加载train参数。

#### E. 三类样本表

依次生成：

```text
q1_windows.parquet
q2_masks.parquet
q3_prefix_features.parquet
```

#### F. 防泄漏测试

至少检查：

- 修改未来帧后，历史输入特征不变；
- 修改0.85秒之后的数据，0.2和0.6秒前缀特征不变；
- test数据变化不影响`normalization.json`；
- Q2遮挡期间真实位置不会出现在策略可见字段中；
- 同一`episode_uuid`不会跨split。

### 暂时不用做

```text
统一头部坐标系
逐帧加速度
复杂插值
轨迹平滑
Transformer输入
EgoDemo独立21点表
dataset embedding
```

这些内容都不是第一版训练的必要条件。

## 6. 建议执行顺序

```text
1. 复核连续块
2. 生成相对位置和因果速度
3. 生成Q1窗口
4. 运行Last Position和Constant Velocity
5. 生成Q2 mask
6. 生成Q3前缀特征
7. 只用train拟合标准化参数
8. 运行防泄漏测试
9. 开始GRU/TCN和时长分位数模型训练
```

## 7. 是否可以立即训练

现有`frames.parquet`可以直接用于编写和验证Baseline，但不应直接作为GRU/TCN的数据集。

正式训练的最低启动条件是：

```text
q1_windows.parquet生成完成
normalization.json只由train计算
窗口防泄漏测试通过
Last Position与Constant Velocity能正常评估
```

达到这四项后，Q1主模型即可开始训练；Q2和Q3随后分别使用自己的样本表，不需要重新读取原始数据。
