# C题模型工程说明

## 1. 目录结构

```text
configs/                 实验参数，不在代码中写死超参数
shuwei_c/datasets/       统一窗口数据接口
shuwei_c/models/         运动学、GRU、TCN和后续模型
shuwei_c/losses.py       MSE与概率损失
shuwei_c/metrics.py      ADE、FDE、RMSE与区间覆盖率
shuwei_c/engine.py       训练、验证、早停和权重保存
scripts/                 训练、评估和冒烟测试入口
work/windows/            预处理生成的模型窗口
work/checkpoints/        模型权重与训练历史
work/results/            统一实验结果
```

## 2. 窗口文件协议

模型不直接读取三套异构原始数据。预处理最终导出NPZ窗口：

```text
x             float32 [N,L,F]
y             float32 [N,H,3]
target_mask   bool    [N,H]
```

`y`定义为相对于最后一个已观测位置的未来三维位移。`x`的前七维冻结为：

```text
[dx, dy, dz, vx, vy, vz,
 observed_mask, time_since_valid_s, raw_quality, hand_side]
```

其余维度可以追加hand side、缺失比例等特征，但不得改变前七维含义。

## 3. 当前模型

| 名称 | 类型 | 概率输出 | 用途 |
|---|---|---:|---|
| `last_observation` | 无参数 | 否 | 最弱基线 |
| `constant_velocity` | 无参数 | 否 | 主要运动学基线 |
| `kalman` | FilterPy适配 | 是 | 传统不确定性基线 |
| `gru` | PyTorch GRU | 可选 | 第一主模型 |
| `tcn` | 因果膨胀卷积 | 可选 | 第二主模型 |
| `quality_gru` | 质量门控概率GRU | 是 | 当前主模型 |

所有模型统一返回：

```python
ForecastOutput(mean=[B,H,3], log_variance=[B,H,3] or None)
```

## 4. 运行

冒烟测试：

```bash
python3 scripts/smoke_test_models.py
```

训练GRU：

```bash
python3 scripts/train_q1.py --config configs/q1_gru_gaussian.yaml
```

训练TCN：

```bash
python3 scripts/train_q1.py --config configs/q1_tcn_gaussian.yaml
```

评估运动学基线：

```bash
python3 scripts/evaluate_q1_baselines.py --config configs/q1_baselines.yaml
```

## 5. 当前边界

- 训练框架已经可以运行，但真实窗口尚未由预处理数据生成；
- Kalman适配器需要安装可选依赖 `filterpy`；
- 当前概率头使用独立高斯方差，后续可增加深度集成或保序校准；
- split必须来自官方环境级划分，禁止对窗口重新随机切分；
- dataset ID默认不进入模型输入，只用于分层评估。

## 6. 三问精简主线

| 问题 | 保留的核心模型/模块 | 不增加的内容 |
|---|---|---|
| Q1 | 联合`QualityAwareGRUForecaster`；普通GRU和TCN只作结构对照 | Transformer、扩散模型、多模态交通预测网络 |
| Q2 | `MissingObservationReplay` + Fixed Interval + Uncertainty Trigger | 强化学习、通用POMDP框架 |
| Q3 | `PrefixDurationQuantileModel` + Risk-Aware Priority + `ScenarioSimulator` | 端到端RL调度、多求解器拼接 |

三问之间只传递有明确含义的量：

```text
Q1: state mean + calibrated uncertainty + reliability
Q2: updated state distribution + request/wait result
Q3: duration quantiles + currently returned information
```

模拟器与模型严格分离：模型可以替换，但Q2/Q3协议、成本和评价规则不随模型变化。

## 7. 因果与信息边界

- Q2私有reference只用于最终评分，不传给策略；
- 请求返回前，策略无法读取请求对应的真实状态；
- Q3真实服务时长只保存在模拟器私有字段中；
- 策略只能读取release、due、weight、zone、predecessor、已返回前缀和执行反馈；
- seed、隐藏source ID、区间终点和未来轨迹不进入策略输入；
- 任何非法动作会记录并终止trial，不静默修复。
