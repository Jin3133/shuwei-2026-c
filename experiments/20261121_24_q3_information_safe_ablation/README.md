# Q3 信息安全统一消融

本实验在修复未释放任务信息泄漏后，重新运行时长模型、排序规则和风险预留消融，共720次配对trial。本实验取代旧的 `20261121_15_q3_unified_ablation`。

## 时长模型

固定 ATC 与 \(r=0.25\)：

| Case | Family准时率 | GBDT准时率 | RF准时率 |
|---|---:|---:|---:|
| S1 | 0.9771 | 0.9792 | **0.9833** |
| S2 | 0.4667 | 0.5389 | **0.6444** |
| S3 | 0.4333 | 0.5188 | **0.5656** |

RF相对GBDT在S2的准时率提高0.1056，95%区间 `[0.0500, 0.1639]`；S3提高0.0469，区间 `[0.0146, 0.0823]`。拖期差异区间也均不跨0，因此模型优势在修复后仍有配对统计支持。

## 排序规则

固定RF与 \(r=0.25\)：

| Case | FCFS | EDD | ATC |
|---|---:|---:|---:|
| S1 | 0.9646 | 0.9708 | **0.9833** |
| S2 | 0.4778 | 0.5292 | **0.6444** |
| S3 | 0.3844 | 0.4885 | **0.5656** |

信息安全的ATC仍在三个场景全部领先。

## 风险预留

| \(r\) | S1准时率 | S2准时率 | S3准时率 | S1/S2/S3 Overrun/s |
|---:|---:|---:|---:|---|
| 0.00 | **0.9896** | **0.7028** | **0.6458** | 21.0 / 27.2 / 35.1 |
| 0.25 | 0.9833 | 0.6444 | 0.5656 | 14.4 / 17.0 / 21.7 |
| 0.50 | 0.9708 | 0.5750 | 0.4656 | 10.1 / 11.2 / 14.0 |
| 1.00 | 0.8292 | 0.4681 | 0.3792 | 4.4 / 4.8 / 6.9 |

\(r=0\)仍是效率上界但容量超限风险最大；\(r=0.25\)在三个名义场景均通过0.5准时率门槛，并显著降低overrun；更保守的预留在S3不满足门槛。因此主方案仍为 `Prefix-specific RF + information-safe ATC + r=0.25`。
