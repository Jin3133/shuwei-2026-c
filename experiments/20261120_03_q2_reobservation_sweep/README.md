# Q2主动重新观测阈值扫描

## 固定条件

```text
split = validation
return delay = 0.2s
request cost = 1
request budget = 2
fixed interval = 0.5s
objective = mean path error + 0.02 * mean requests
```

请求时只捕获当前真实记录中存在的状态，延迟结束后才加入观测历史。等待期间继续预测。策略看不到mask终点，因而无法避免“请求尚未返回，mask已经结束”的情况。

## 汇总结果

| 策略 | 路径误差/m | 终点误差/m | 平均请求 | 目标值 |
|---|---:|---:|---:|---:|
| 不请求 | 0.07018 | 0.12698 | 0.000 | 0.07018 |
| 固定0.5s | **0.05171** | 0.08969 | 1.148 | 0.07467 |
| 阈值0.05 | 0.05857 | 0.11755 | 1.793 | 0.09444 |
| 阈值0.10 | 0.05307 | 0.09584 | 1.381 | 0.08069 |
| 阈值0.15 | 0.05176 | 0.09135 | 1.381 | 0.07938 |
| 阈值0.20 | 0.05486 | 0.08422 | 0.972 | 0.07430 |
| 阈值0.25 | 0.05898 | **0.08326** | 0.776 | 0.07451 |
| 阈值0.30 | 0.06059 | 0.09978 | **0.384** | **0.06828** |

## 结论

阈值0.05—0.15请求过于频繁，部分短mask中请求尚未返回便结束，成本没有换来等量收益。阈值0.20、0.25、0.30与固定策略形成清晰Pareto前沿。

在当前成本权重0.02下冻结候选阈值：

\[
\boxed{\tau=0.30\text{ m}}
\]

它相对不请求将平均路径误差降低约13.7%，平均请求仅0.384次。若研究重点改为纯精度，应选择固定0.5秒策略；因此论文必须同时报告误差和请求数，不只报告自定义目标。

## 限制

- 本实验是validation上的策略选择，不是最终泛化结果；
- 请求返回后使用两个合法观测之间的速度并进行指数收缩，没有调用未来轨迹；
- 1.5和2秒初始开环预测在1秒后保持不变，长mask收益主要来自重新观测；
- 需要对request cost、delay和预算做敏感性分析后再最终冻结。
