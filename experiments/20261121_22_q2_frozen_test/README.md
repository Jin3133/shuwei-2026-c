# Q2 官方 test 冻结回放

## 信息边界

本实验在 7,478 个官方 test masks 上进行一次冻结回放。模型权重、校准系数、触发阈值、返回延迟、请求预算和运动收缩系数均在 test 之前确定。策略在请求时只能捕获原记录当时真实存在的状态，并在 0.2 秒延迟结束后获得该观测；masked trajectory 只供评分。

冻结策略为：

- 不请求；
- 固定 0.5 秒请求；
- pooled conformal + 样本级方差，阈值 0.25 m；
- worst-environment conformal + 样本级方差，阈值 0.35 m。

## 总体结果

| 策略 | 路径误差（m） | 终点误差（m） | 平均请求 | 等待暴露（s） |
|---|---:|---:|---:|---:|
| 不请求 | 0.13744 | 0.27689 | 0.000 | 0.000 |
| 固定 0.5 s | **0.07723** | 0.14613 | 1.387 | 0.277 |
| pooled 0.25 m | 0.08863 | 0.14093 | 0.861 | 0.172 |
| robust 0.35 m | 0.09134 | **0.14063** | **0.805** | **0.161** |

相对不请求，pooled 与 robust 分别将路径误差降低约 35.5% 和 33.5%，终点误差降低约 49.1% 和 49.2%。

相对固定间隔：

- pooled 少请求约 38.0%，终点误差低约 3.6%；
- robust 少请求约 42.0%，终点误差低约 3.8%；
- 固定间隔的全路径平均误差最低。

因此，固定策略适合观测便宜且强调全程轨迹精度的场景；不确定性触发适合观测有成本、强调关键终点风险的场景。

## 不同遮挡长度

0.2 秒时各种策略误差相同，主动请求几乎没有收益。0.5 秒时请求返回时间接近 mask 终点，固定策略平均请求 1 次却没有改善误差。主动策略在短 mask 上基本不请求。

在 1.0–2.0 秒长遮挡中，主动观测收益明显。以 pooled 为例：

| mask 时长 | 不请求路径误差 | pooled 路径误差 | pooled 平均请求 |
|---:|---:|---:|---:|
| 1.0 s | 0.13338 | 0.10701 | 0.968 |
| 1.5 s | 0.20975 | 0.12220 | 1.442 |
| 2.0 s | 0.27960 | 0.14336 | 1.821 |

这与第二问的核心判断一致：短遮挡继续预测，长遮挡随着风险增长主动获取新观测。

## 成本解释

对目标

\[
J=E_{\mathrm{path}}+\lambda N_{\mathrm{obs}},
\]

官方 test 的冻结结果显示：低成本时固定间隔最优；当每次请求的等价误差成本上升到约 0.022 m 后，样本级不确定性策略比固定间隔更合算。该临界值只作为 test 敏感性解释，不用于重新选择阈值。

## 最终建议

论文主策略采用 `pooled 0.25 m`，因为它是 validation 在中等成本区间选出的策略，并在官方 test 上取得更低的路径误差。`robust 0.35 m` 作为保守策略：请求更少、终点误差略低，同时具有更可靠的风险半径解释。固定间隔、不请求作为上下界基线。

需要明确：1 秒以上的半径是触发分数的延伸，不具有严格 90% 覆盖保证；其合理性来自冻结回放中的决策收益，而不是概率覆盖声明。
