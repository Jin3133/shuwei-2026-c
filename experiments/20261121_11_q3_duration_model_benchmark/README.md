# Q3时长模型受控基准

## 设计

参考主动特征获取基准的统一数据、成本与评价协议，只比较三种成熟树模型：GBDT、Random Forest、Extra Trees。每个前缀独立训练，所有校准参数均来自训练环境分组OOF预测。

调研参考：

- DIVA的核心原则是只有信息足以改变决策且收益超过成本时才获取；
- AFA-Benchmark强调在相同预算和数据协议下比较 acquisition 方法。

## 结果

| Prefix | 模型 | Q50 MAE/s | Q80覆盖率 | Q80 Pinball |
|---:|---|---:|---:|---:|
| 0.2 | GBDT | 3.313 | 0.800 | **1.067** |
| 0.2 | Random Forest | **2.927** | 0.743 | 1.273 |
| 0.2 | Extra Trees | 3.359 | 0.800 | 1.372 |
| 0.6 | GBDT | 3.368 | 0.771 | **1.100** |
| 0.6 | Random Forest | **2.804** | 0.857 | 1.175 |
| 0.6 | Extra Trees | 3.348 | 0.829 | 1.294 |
| 1.0 | GBDT | 3.350 | 0.657 | 1.400 |
| 1.0 | Random Forest | **3.325** | 0.800 | **1.228** |
| 1.0 | Extra Trees | 3.503 | 0.829 | 1.469 |

## 决策

Random Forest在0.2和0.6秒点预测上明显领先，且1.0秒不劣于GBDT，因此进入调度验证。Extra Trees不再继续。最终模型仍以调度指标决定，而不是只按单个预测指标选择。
