# Q3分前缀GBDT实验

## 目的

检验0.2、0.6、1.0秒前缀共用一个模型是否压制了后续观测的信息增益。三个前缀分别训练GBDT，并在训练环境分组OOF残差上独立校准。

## 结果

| Prefix | Raw Q50 MAE/s | 校准Q80覆盖率 | 校准Q80 Pinball |
|---:|---:|---:|---:|
| 0.2 | **3.262** | 0.800 | **1.067** |
| 0.6 | 3.339 | 0.771 | 1.100 |
| 1.0 | 3.312 | 0.657 | 1.400 |

0.2秒独立模型优于原共享模型，但误差没有随前缀增长单调下降。说明分前缀训练本身不能解决后续信息价值不足，需要比较更适合小样本表格数据的模型。
