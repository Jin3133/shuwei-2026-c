# 实验记录规范

每次正式实验创建一个独立目录：

```text
experiments/YYYYMMDD_序号_简短名称/
├── config.yaml
├── results.json
└── README.md
```

必须记录：

- 实验目的和预先提出的问题；
- 数据交付版本、split和样本数；
- Git提交；
- 模型、权重和关键超参数；
- 策略可见字段与私有评分字段；
- 完整比较方法；
- 逐horizon指标；
- 异常、失败和限制；
- 本轮结论与下一轮唯一主要调整。

禁止根据test结果修改模型、阈值或策略。`work/`中的大文件、权重和逐样本日志不提交Git；小型汇总结果和实验说明提交。
