# Q1 官方 test 冻结评估

## 目的与信息边界

本实验只做一次官方 `test` 冻结评估。模型权重、物理基线参数、分时域收缩系数和 conformal 系数均在 train/validation 阶段确定；本实验未利用 test 标签重新训练或调整任何参数。

评估包含 22,803 个窗口、7 条记录和 4 个官方测试环境。误差均在原始物理坐标中计算，单位为米。

## 点预测结果

| 方法 | 0.2 s | 0.5 s | 1.0 s | 平均 ADE |
|---|---:|---:|---:|---:|
| Last Position | 0.0785 | 0.1850 | 0.3401 | 0.2012 |
| Constant Velocity | 0.0318 | 0.1201 | 0.3234 | 0.1584 |
| Kalman | 0.0561 | 0.1593 | 0.3688 | 0.1947 |
| MSE-GRU | 0.0363 | **0.1088** | **0.2638** | **0.1363** |
| Gaussian-GRU | **0.0315** | 0.1101 | 0.2737 | 0.1384 |
| MSE-GRU + shrink | 0.0363 | 0.1172 | 0.2787 | 0.1441 |
| Gaussian-GRU + shrink | 0.0315 | 0.1198 | 0.2883 | 0.1465 |

MSE-GRU 的整体点预测最好。以官方环境为配对单位，它相对 Constant Velocity 和 Kalman 在 4/4 个环境中胜出；相对 Gaussian-GRU 在 3/4 个环境中胜出。

## 收缩层为何淘汰

验证集交叉拟合曾表明长时域收缩有效，但冻结后在 test 上反而使 MSE-GRU 的 ADE 从 0.1363 m 上升至 0.1441 m。主要原因是数据源组成发生变化：test 中 EgoStandard 占 16,132/22,803 个窗口，而 validation 中只有 698 个 EgoStandard 窗口。全局收缩系数对测试阶段较大的运动幅度产生系统性低估。

因此，收缩层作为完整消融结果保留，但不进入最终方法。该处理不是根据 test 重新调参，而是拒绝一个未能通过冻结外部评估的附加模块。

## 冻结不确定性校准

Gaussian-GRU 使用 validation 上已冻结的 90% conformal 半径，直接应用于 test：

| 时域 | 冻结系数 | test 覆盖率 | 平均半径（m） |
|---|---:|---:|---:|
| 0.2 s | 1.7096 | 91.57% | 0.0643 |
| 0.5 s | 1.6883 | 85.12% | 0.1818 |
| 1.0 s | 1.4997 | 69.21% | 0.3422 |

短时覆盖率达到目标，但中长时域在分布偏移下明显低于 90%。因此 Gaussian-GRU 的不确定性适合用于风险排序和重新观测触发，不应在论文中表述为跨数据源严格校准的概率。长遮挡下覆盖率下降本身也支持“不确定性随遮挡增长并需要主动重新观测”的建模动机。

## 最终 Q1 结构

- 点预测主模型：MSE-GRU；
- 概率辅助模型：Gaussian-GRU；
- 不确定性输出：Gaussian-GRU 方差乘 validation 冻结 conformal 系数；
- 物理基线：Last Position、Constant Velocity、Kalman；
- 被拒绝的消融：分时域全局收缩。

第一问最终不再增加模型。后续第二问将 MSE-GRU 作为轨迹误差主线，将 Gaussian-GRU 不确定性作为重新观测决策信号，并单独报告长时域校准失配。

详细数值见 `results.json`。
