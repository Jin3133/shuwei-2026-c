# Q3最终统一消融实验

## 实验协议

所有候选共享名义映射、官方30个validation种子、相同任务抽样、无付费查看和同一严格仿真器。每次只改变时长模型、排序规则或风险预留强度，共720条trial。

## 时长模型消融

固定ATC与 \(r=0.25\)：

| Case | 模型 | 完成率 | 准时率 | 加权拖期/s |
|---|---|---:|---:|---:|
| S1 | Family | 1.000 | 0.977 | 1.4 |
| S1 | GBDT | 1.000 | 0.979 | 1.2 |
| S1 | Random Forest | **1.000** | **0.983** | **1.1** |
| S2 | Family | 0.806 | 0.467 | 107.2 |
| S2 | GBDT | 0.844 | 0.539 | 67.6 |
| S2 | Random Forest | **0.851** | **0.622** | **60.3** |
| S3 | Family | 0.779 | 0.433 | 227.4 |
| S3 | GBDT | 0.819 | 0.519 | 161.7 |
| S3 | Random Forest | **0.836** | **0.559** | **149.5** |

RF相对GBDT的准时率提升在S2为+0.0833，Bootstrap 95% CI为[0.0347,0.1361]；S3为+0.0406，区间[0.0135,0.0688]。S2、S3拖期下降的区间也均不跨0。因此RF改进获得配对统计支持。

## 排序规则消融

固定RF与 \(r=0.25\)：

| Case | FCFS准时率 | EDD准时率 | ATC准时率 |
|---|---:|---:|---:|
| S1 | 0.965 | 0.971 | **0.983** |
| S2 | 0.478 | 0.529 | **0.622** |
| S3 | 0.384 | 0.489 | **0.559** |

ATC在三个场景均领先，S2、S3优势明显，说明同时考虑权重、处理时间和截止期松弛度比单纯到达顺序或最早截止期更合适。

## 风险预留消融

固定RF与ATC，预留为

\[
b_j=Q_{0.5,j}+r(Q_{0.8,j}-Q_{0.5,j})+\beta.
\]

| r | S1准时率 | S2准时率 | S3准时率 | S1/S2/S3 Overrun/s | S1/S2/S3 Idle/s |
|---:|---:|---:|---:|---|---|
| 0.00 | **0.990** | **0.706** | **0.644** | 21.0 / 27.2 / 34.7 | 2.6 / 3.1 / 4.1 |
| 0.25 | 0.983 | 0.622 | 0.559 | 14.3 / 16.8 / 21.6 | 6.8 / 8.2 / 11.0 |
| 0.50 | 0.971 | 0.558 | 0.464 | 10.1 / 11.3 / 14.0 | 13.4 / 15.4 / 20.2 |
| 1.00 | 0.829 | 0.453 | 0.379 | **4.4 / 4.7 / 6.9** | 28.8 / 30.0 / 37.1 |

官方将overrun定义为容量风险，并规定以成本或容量风险为主目标时，名义三场景平均加权准时率均须至少0.50。若采用统一全场景风险水平，则：

- \(r=0\)效率最高，但容量风险最大；
- \(r=0.5\)和 \(r=1\)因S3准时率低于0.50而不满足门槛；
- \(r=0.25\)是通过三个场景门槛的候选中overrun更低的风险约束解。

因此保留 \(r=0.25\) 作为风险感知主方案，同时将 \(r=0\) 报告为风险中性效率上界。不能声称 \(r=0.25\) 在所有均值指标上最优。

## 最终结论

第三问主方案冻结为 `Prefix-specific Random Forest + ATC + r=0.25`。Family、GBDT、FCFS、EDD及不同预留强度均保留为正式消融；VOI作为扩展实验，不进入核心策略。
