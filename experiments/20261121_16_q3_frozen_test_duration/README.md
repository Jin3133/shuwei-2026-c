# Q3冻结模型Test时长评估

## 边界

交付数据包含62个test语义区间、7条记录、4个test环境及对应前缀特征，但当前公开附件和赛事官网均未提供第三问调度所需的30个额外冻结test种子。因此本实验只评价冻结时长模型，不生成或冒充官方调度test结果。

模型结构、超参数和训练环境OOF校准均在读取test目标前冻结。本轮结果不得继续用于调参或重新选择模型。

## 解释

- Random Forest在validation的点预测优势没有迁移到test，存在验证集选择偏差；
- GBDT在三个test前缀的Q50 MAE均更低，且随前缀增长略有改善；
- 0.2秒时RF的Q80 Pinball与GBDT接近，但覆盖率更接近目标0.8；
- 该结果只能说明时长预测泛化，不等价于调度表现；调度最终比较仍需要官方test种子。

## 冻结原则

不根据本轮test结果回头修改validation选择过程。论文应分别报告validation模型选择和test泛化差距，并将“RF在validation调度更好”限定在validation证据范围内。完整预测见 `predictions.csv`，汇总见 `results.json`。
