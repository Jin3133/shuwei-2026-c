# Q1–Q2 不确定性稳健校验

## 要回答的问题

Gaussian-GRU 的预测方差能否经过 validation 校准，作为第二问“继续预测还是重新观测”的风险信号？

目标覆盖率设为 90%。全部校准系数只由 validation 残差计算。官方 test 只用于冻结后的敏感性报告，不参与系数拟合。

## 对照方法

1. `pooled`：每个预测时域在全部校准样本上计算一个 conformal 系数；
2. `worst_environment`：先在每个官方验证环境内计算 conformal 系数，再取其中最大值。

第二种方法不改变 GRU，也不把 dataset ID 输入模型，只对输出半径进行保守校准。

## 留一环境交叉校验

每次留出一个官方 validation 环境，其余环境计算系数，在未参与校准的环境上检查覆盖率。

| 方法 | 0.2 s | 0.5 s | 1.0 s |
|---|---:|---:|---:|
| pooled（按窗口汇总） | 89.04% | 91.44% | 91.33% |
| worst-environment（按窗口汇总） | 90.92% | 93.89% | 95.47% |
| worst-environment（环境等权） | 91.55% | 92.13% | 92.85% |

稳健方法在四个留出环境上的最低覆盖率分别为 90.0%、89.6% 和 89.1%，没有出现由单个环境完全支撑总体结果的情况。

## 冻结后的官方 test 敏感性结果

| 方法 | 指标 | 0.2 s | 0.5 s | 1.0 s |
|---|---|---:|---:|---:|
| pooled | 覆盖率 | 91.57% | 85.12% | 69.21% |
| worst-environment | 覆盖率 | **92.29%** | **91.24%** | **86.32%** |
| pooled | 平均半径（m） | 0.064 | 0.182 | 0.342 |
| worst-environment | 平均半径（m） | 0.066 | 0.217 | 0.474 |

环境稳健校准修复了 0.5 秒覆盖率，并使 1.0 秒覆盖率提高约 17.1 个百分点，但 1.0 秒仍未达到 90%，同时区间明显变宽。

## 对第二问的使用结论

- 推荐使用 `worst_environment` 半径作为重新观测策略的保守风险信号；
- 0.2 秒和 0.5 秒可以报告接近目标的经验覆盖率；
- 1.0 秒只能表述为“显著改善但仍存在跨域欠覆盖”，不能宣称严格 90% 校准；
- 半径越大仍能表示风险越高，因此可以用于阈值触发和策略排序；
- 超过 1.0 秒没有原生预测时域与可靠校准证据，应进入强制重新观测或单独的长遮挡策略，不能外推 90% 概率保证。

该实验支持一个精简结论：不需要增加新的预测网络，只需把 pooled conformal 替换为环境稳健 conformal，并保留长时域失配说明。
