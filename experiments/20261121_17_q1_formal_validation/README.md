# Q1物理单位正式验证

## 修正内容

旧基线脚本将标准化速度直接用于物理位移外推，并保留了30步旧配置，不能作为正式结果。本实验直接从交付parquet读取米和秒单位的位置、速度与目标；神经模型仍使用训练时的标准化NPZ输入。三个实际预测距离为0.2、0.5和1.0秒。

validation包含12141个窗口、7条记录、4个环境，三个目标均有效。所有Q1输入质量标记均为1，因此Q1窗口内无法进行质量高低分层；质量退化实验归入Q2人工mask回放。

## 主要结果

| 模型 | 0.2s误差/m | 0.5s误差/m | 1.0s误差/m | Overall ADE/m |
|---|---:|---:|---:|---:|
| Last Position | 0.04124 | 0.08877 | **0.15097** | 0.09366 |
| Constant Velocity | 0.02999 | 0.10043 | 0.23688 | 0.12243 |
| Kalman | 0.04455 | 0.11403 | 0.23758 | 0.13205 |
| MSE GRU | 0.02981 | **0.07767** | 0.15359 | **0.08702** |
| Gaussian GRU | **0.02681** | 0.07841 | 0.15701 | 0.08741 |

Gaussian GRU在0.2秒明显最好，但在1秒略逊于Last Position，说明模型存在随预测距离增加的位移过预测。MSE与Gaussian GRU总体差异很小。

## 不确定性

Gaussian GRU的原始轴向95%区间联合覆盖率分别为0.821、0.834、0.867；预测标准差与实际误差相关性分别为0.551、0.500、0.394。模型能识别部分困难样本，但长时不确定性排序能力下降。

## 分层现象

EgoStandard的Gaussian GRU ADE约0.149m，明显高于EgoDemo的0.094m和EgoPro的0.081m，说明跨数据源泛化是主要误差来源。左右手差异较小。

## 决策

不更换GRU架构，优先修正稳定的长时过预测偏差，并保留Gaussian输出作为Q2不确定性接口。
